# MAX Session Lab

Telegram-бот для локального подсчёта записей в `.json`, `.txt`, `.js` и `.zip`.

> Бот не авторизуется в Telegram, не проверяет сессии в сети и не выполняет спам-действия. Статусы в отчёте предназначены только для структурной локальной сводки.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export BOT_TOKEN='токен-от-BotFather'
python bot.py
```

Для JSON поддерживаются массивы и объекты с ключами `accounts`, `sessions`, `data`, `items`, `users`. В текстовых файлах каждая непустая строка считается записью; в ZIP анализируются вложенные поддерживаемые файлы.

## Баланс и администраторы

- Первый `/start` начисляет $5.000; каждая обработка списывает $0.001.
- `/balance` показывает баланс.
- Задайте `ADMIN_IDS` (через запятую) для получения уведомлений. Администратор может добавить другого командой `/addadmin ID`.
- Пополнение через Crypto Bot требует подключения API Crypto Pay; в текущей версии предусмотрено уведомление пользователю, а сетевые платежи намеренно не реализованы.
